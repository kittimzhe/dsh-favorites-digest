# Security Policy / 安全策略

## Supported versions / 支持版本

Only the latest published release is supported. / 仅支持最新发布版本。

## Reporting a vulnerability / 报告漏洞

**Do not open a public issue for security problems. / 请勿为安全问题创建公开 issue。**

Please use GitHub's private vulnerability reporting: **Security tab → "Report a vulnerability"**. / 请使用 GitHub 私密漏洞报告：仓库 **Security 标签页 → "Report a vulnerability"**。

This plugin only exports the operator's own logged-in web favorites. Do not use it to access another person's account. / 本插件只导出操作者自己已登录的 web 收藏，请勿用于访问他人账号。
